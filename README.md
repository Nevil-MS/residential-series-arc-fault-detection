# Arc Fault Detection using Machine Learning

## Overview

This project explores the use of Machine Learning techniques for detecting **series arc faults** in residential AC electrical systems using current waveform data.

The objective is to investigate whether classical machine learning algorithms such as **Random Forest** and **Support Vector Machine (SVM)** can accurately distinguish between normal electrical operation and series arc faults through feature engineering.

This project is part of an academic study on residential arc fault detection.

---

## Dataset

The project uses the publicly available dataset from:

**Real-Time Series Arc Fault Detection and Appliances Classification in AC Networks Based on Competing Convolutional Kernels**

The dataset can be downloaded from Zenodo.

See **DATASET.md** for download and installation instructions.
